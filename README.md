# البروتوكول الشهري لإعادة التناغم مع المال — نسخة التطبيق (PWA)

## المحتويات
- `index.html` — التطبيق كامل (يعمل بدون إنترنت بعد أول فتحة)
- `manifest.webmanifest` — بيانات التثبيت (الاسم، الأيقونة، شاشة البداية)
- `sw.js` — Service Worker للعمل offline
- `icon-192.png` / `icon-512.png` / `icon-512-maskable.png` — الأيقونات

## طريقة النشر (أسهل 3 خيارات)
1. **Netlify Drop** — ادخل `app.netlify.com/drop` واسحب مجلد `protocol-app` كامل. هيديك لينك HTTPS فورًا.
2. **GitHub Pages** — ارفع محتويات المجلد على repo ← Settings ← Pages ← Deploy from branch.
3. **أي استضافة** عندك (لازم HTTPS عشان الـ Service Worker يشتغل).

⚠️ لازم HTTPS. فتح الملف من الجهاز مباشرة (file://) هيشغّل التطبيق لكن من غير تثبيت ولا offline.

## التثبيت على الموبايل
- **أندرويد (Chrome):** افتح اللينك ← هيظهر زر «تثبيت التطبيق» فوق، أو قائمة ⋮ ← «تثبيت التطبيق».
- **آيفون (Safari فقط):** افتح اللينك ← زر المشاركة ⬆︎ ← «إضافة إلى الشاشة الرئيسية».

بعد التثبيت بيفتح بملء الشاشة بدون شريط المتصفح — شكله وسلوكه تطبيق عادي، وبياناتك محفوظة على الجهاز.

## ملف APK (اختياري)
لو محتاج APK فعلي للأندرويد: ادخل `pwabuilder.com` ← حط لينك التطبيق بعد نشره ← Package for stores ← Android. بيطلّع لك APK/AAB موقّع جاهز للتثبيت المباشر أو للرفع على Play Store.

## ملاحظة
توليد برنامج EFT تلقائيًا يشتغل في النسخة المنشورة داخل Claude فقط. في نسخة الـ PWA فيه مربع تكتب/تلصق فيه البرنامج يدويًا، وتنزيل ملف Word شغال في النسختين.
